如何用带批注的截图提交网站 Bug？

直接指出问题位置，让接收者看懂哪里出错，而不必从空白截图中猜测。

添加到 Chrome

具体怎么操作？

  1. 打开出现问题的网页，在当前可见区域复现问题。
  2. 用箭头指出问题位置，再用文字框写明预期行为和实际行为。
  3. 截取带批注的可见区域。Pro 提供无水印和 3X 高清 PNG；还可将反馈复制或下载为 Markdown 与彩色 HTML。

开始前需要了解哪些限制？

哪些功能免费，哪些需要 Pro？

免费版提供标注工具，每页最多合计 20 条标注，普通截图带水印。Pro 不限标注数量、截图无水印，支持 3X 高清 PNG、复制或下载 Markdown 与彩色 HTML 反馈、导出到 Obsidian、本地历史和自定义来源信息。

可以复制或导出反馈吗？

Pro 可复制 HTML 或 Markdown 反馈，下载 HTML 或 Markdown 文件，或将 Markdown 笔记发送到 Obsidian 并同时下载备份。HTML 保留高亮颜色。截图仅包含当前可见区域；菜单不提供整页截图或 PDF 导出。
