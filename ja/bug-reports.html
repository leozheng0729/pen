注釈付き画像でサイトの不具合を報告するには？

問題の位置を正確に示せます。

Chrome に追加

操作手順は？

  1. 問題のページを開き、表示範囲内で不具合を再現します。
  2. 矢印で場所を示し、期待する動作と実際の動作を文字で説明します。
  3. 注釈付きの表示範囲を撮影します。Pro は透かしなし・3倍 HD PNG に対応し、Markdown または色付き HTML フィードバックをコピー・保存できます。

始める前に知っておくことは？

無料版と Pro の違いは？

無料版は注釈ツール、1ページ合計20件までの注釈、透かし入りの通常スクリーンショットに対応します。Pro は件数制限と透かしをなくし、3倍の HD PNG、Markdown と色付き HTML フィードバックのコピー・ダウンロード、Obsidian 書き出し、ローカル履歴と独自の出典情報を追加します。

フィードバックをコピーまたは書き出せますか？

Pro は HTML または Markdown をコピー、ファイルとしてダウンロード、または Markdown ノートとして Obsidian に送信できます。Obsidian 送信時はバックアップもダウンロードします。HTML はハイライト色を保持します。撮影範囲は表示中の領域のみで、メニューにページ全体の撮影や PDF 書き出しはありません。
